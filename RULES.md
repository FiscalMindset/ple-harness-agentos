# Competition rules checklist (from the Kaggle competition description)

## Repo

- Public repo; if private during the competition, install the ple-submission GitHub App and make it public at close.
- One GitHub repo URL under Project Links, plus the 40-character commit SHA (`git rev-parse HEAD`) at the top of the Writeup.
- That commit must contain: submission.yaml (one of the 8 google-cloud/<id> models), serve.py, harness.py, Apache-2.0 or MIT LICENSE, and the unpacked artifacts/ from `uv run python eval/run.py`.
- artifacts/: unpacked directory, <=512 MiB, <=10,000 files, no Git LFS, no symlinks.
- Pass `uv run python -m kit check` and `uv run python -m kit artifacts`.
- model_api in submission.yaml must match the model the harness actually calls.
- Local dev may use a self-hosted open-weight model or personal API; document which local model and judge setup in the Writeup. The evaluation proxy blocks custom keys/external servers/web search in Stage 2.

## Writeup

- One Kaggle Writeup, <=2000 words. Un-submitted drafts are not judged; can edit and resubmit before deadline.
- Cover all 5 Stage 1 rubric criteria: Insight & Failure Analysis (25), Engineering Reasoning (25), Cross-Model Generalizability (15), Efficiency & Scaling (20), Clarity & Visuals (15).
- Media Gallery cover image.
- 3 figures: (1) architecture diagram, (2) score-vs-cost plot, (3) failure breakdown on the 29 dev tasks.
- If using an open-weight/local judge (JUDGE_MODEL), state which judge model was used.

## Stages

- Stage 1: 100-point Writeup + pre-screening qualification gate; top 100 advance.
- Stage 2: 56 hidden tasks, 3 independent runs each (168 task runs), 6-hour limit per task, 2 CPUs / 4 GB RAM, read-only /opt/harness, writable 1 GB /tmp and $HOME.
  Grading: quantitative checks, CAD/IFC geometry, constraints, LLM judge (Claude Opus 5.5) on open-ended deliverables, 0.0-1.0 scale. No done/error frame scores 0.0.
  Finalists need mean >= 0.138 to qualify for the performance-cost Pareto frontier and prizes.
  Ranked by mean Stage 2 test score among Pareto-frontier entries; ties broken by Stage 1 Writeup score, then earlier submission timestamp.
